# Wanderlust – Travel Recommendation Web App

A multi-page travel website featuring search functionality for beaches, temples, and countries.

## Pages

- **Home** (`index.html`) – Hero, search bar, category cards
- **About Us** (`about.html`) – Team bios and story
- **Contact Us** (`contact.html`) – Email contact form

## Features

- Search for beaches, temples, or countries
- Each result shows 2 images and a description
- Responsive on mobile
- Contact form with success confirmation
